Environment Switcher Settings

Configure which environments appear in the chooser and which sites can be opened from the toolbar.

One per line: NAME = branch. For example: DEV = develop, UAT = uat, PRD = main.
Branches must be lowercase (a-z, 0-9, and -).

One per line: original-site = repo--org. For example: www.example.com = mysite--myorg.
Optional path prefix: www.example.com/content/brand = site--org to map AEM-style URLs.
